Repositori ini berisi penyelesaian tugas Pemrograman Dasar TLS 2026 yang terbagi menjadi dua fase:

Fase 1 (Logika & Perancangan):
Berisi satu berkas PDF yang mencakup pseudocode dan flowchart untuk penyelesaian dua masalah utama: Problem 1 (The Last Astronaut) dan Problem 2 (Alien-In-The-Middle).
Dilengkapi dengan penjelasan logika algoritma untuk masing-masing masalah (minimal 2 paragraf per masalah).

Fase 2 (Implementasi C++):
problem1.cpp: Program C++ yang mengimplementasikan simulasi eliminasi astronot melingkar dengan aturan pembaruan nilai $K$ secara dinamis berbasis ganjil-genap.
problem2.cpp: Program C++ yang mengimplementasikan sistem enkripsi sandi rahasia berdasarkan pergeseran nilai alfabet dari huruf sebelumnya.
Seluruh kode C++ dibuat tanpa library tambahan selain <iostream> dan menggunakan fungsi buatan sendiri (user-defined functions) tanpa fungsi bawaan library.
